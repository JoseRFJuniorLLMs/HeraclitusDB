# SPEC-0048 — Forge Orchestrator & Forensic Evidence Plane

**Status:** Draft / Proposed
**Autor:** Heraclitus Core, Forge & Security Team
**Data:** Agosto de 2026
**Classe:** SOAR / Orchestration / Case Management / Digital Forensics
**Prioridade:** P1
**Novos crates recomendados:**`heraclitus-orchestrator`, `heraclitus-forensic`
**Integração:**`heraclitus-sentinel`, `heraclitus-compliance`, `heraclitus-server`, Forge, Dashboard
**Compatibilidade:** Rust Stable
**Princípio:***Automation executes policy; forensics preserves evidence; the UI does neither.*

---

# 0. Decisão Arquitetural

A lógica SOAR NÃO deve morar em:

```text
dashboard/ui
```

nem diretamente em:

```text
server/rest.rs
```

A interface apenas edita e visualiza.

O motor deve existir como componente independente:

```text
heraclitus-orchestrator
```

e o plano pericial:

```text
heraclitus-forensic
```

# 39. Cadeia de Custódia

O art. 158-A do CPP define cadeia de custódia como os procedimentos usados para manter e documentar a história cronológica do vestígio, inclusive posse e manuseio.

O Heraclitus pode fornecer suporte técnico para essa rastreabilidade.

Não deve declarar que software sozinho satisfaz toda exigência jurídica.

# 61. Gates

## O0 — DAG

Playbook cíclico inválido é rejeitado.

## O1 — Type Safety

Parâmetro incompatível falha antes da execução.

## O2 — Approval

Nó que exige aprovação não pode ser pulado.

## O3 — Crash

Run interrompido recupera sem duplicar efeito.

## O4 — Secret

Segredo nunca aparece no YAML, log ou LLM.

## O5 — Idempotency

Retry não duplica ação externa.

## F0 — Package Integrity

Um byte alterado quebra verificação.

## F1 — Merkle

Evento falso não passa inclusão.

## F2 — Timestamp

Anchor inválido é detectado.

## F3 — Custody

Transferência deixa rastro.

## F4 — Offline Verification

Pacote é verificável sem o servidor original.
