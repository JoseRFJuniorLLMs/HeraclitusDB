# SPEC-0047 — Heraclitus Threat-Sync: Sovereign Threat Intelligence & Government Incident Exchange

**Status:** Draft / Proposed
**Autor:** Heraclitus Core & Security Team
**Data:** Agosto de 2026
**Classe:** Threat Intelligence / STIX / TAXII / MISP / Government Exchange
**Prioridade:** P1
**Alvo primário:**`heraclitus-sentinel::threat`
**Integração:**`heraclitus-index-text`, `heraclitus-index-vector`, `heraclitus-index-attr`, `heraclitus-proto`, `heraclitus-compliance`
**Compatibilidade:** Rust Stable
**Princípio:***Threat intelligence is evidence with provenance, expiration and trust, not a magic list of evil strings.*

---

# 0. Decisão Arquitetural

O `Heraclitus Threat-Sync` implementa o plano de **Cyber Threat Intelligence** do ecossistema.

Ele deve:

1. importar inteligência externa;
2. normalizar indicadores;
3. preservar origem;
4. validar confiança;
5. deduplicar;
6. expirar;
7. correlacionar com eventos locais;
8. enriquecer incidentes;
9. compartilhar inteligência sanitizada;
10. funcionar conectado ou air-gapped.

---

# 1. Protocolos

Baseline:

```text
STIX 2.1
TAXII 2.1
MISP Core Format
TLP 2.0
```

STIX 2.1 e TAXII 2.1 são padrões OASIS, sendo TAXII um protocolo REST para intercâmbio de CTI e com suporte obrigatório a STIX 2.1.

O MISP possui formato próprio publicado para troca de eventos, atributos e inteligência, que evolui independentemente de STIX.

Consequentemente, a SPEC MUST NOT hardcodar:

```text
MISP Format = "1.5 forever"
```

---

# 2. CTIR Gov

O CTIR Gov será tratado através de:

```rust
pub trait GovernmentIncidentChannel
```

e não presumido como TAXII.

A orientação oficial atual utiliza notificação institucional e TLP 2.0, inclusive indicando `ctir@ctir.gov.br` como ponto de contato para incidentes.

# 7. Exact Match Primeiro

IOCs exatos devem utilizar estruturas exatas.

```text
IP       → radix/prefix structure
hash     → hash map
domain   → normalized suffix trie
string   → exact/inverted index
```

Bloom Filter MAY atuar apenas como prefilter.

Por possuir falsos positivos:

```text
Bloom match != confirmed IOC match
```

# 13. Feed Poisoning

Um atacante pode comprometer uma fonte de intelligence.

Portanto:

```text
source != truth
```

O sistema MUST suportar:

* assinatura do feed;
* TLS;
* pinning opcional;
* source reputation;
* confidence;
* quarantine;
* abrupt-change detection;
* rate limits;
* rollback de versão.

---

# 14. Feed Explosion

Entrada externa MUST possuir:

```text
max object size
max bundle size
max indicators
max relationships
max nesting
parser timeout
```

para impedir DoS por payload.

# 43. Gates

## T0 — STIX Interoperability

Corpus STIX válido importa/exporta sem perda dos campos suportados.

## T1 — TAXII

Cliente passa casos de interoperabilidade do padrão 2.1 aplicáveis.

## T2 — MISP

Fixtures reais de MISP importam e reexportam.

## T3 — Bloom Safety

Bloom false positive nunca gera match confirmado sozinho.

## T4 — Poisoning

Feed não confiável não pode habilitar resposta automática de alto impacto.

## T5 — TLP

TLP RED nunca sai para destino não autorizado.

## T6 — Air-Gap

Bundle adulterado é rejeitado.

## T7 — CTIR

Renderizador gera notificação consistente sem presumir API inexistente.

